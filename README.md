PneusMedidas 🚗

O PneusMedidas é uma aplicação web desenvolvida para comparar visualmente diferentes medidas de pneus. A ferramenta permite adicionar até 6 pneus simultaneamente e visualizar suas diferenças de largura, altura do perfil e diâmetro, facilitando a análise antes de escolher uma nova medida.

✨ Funcionalidades
Comparação de até 6 medidas de pneus simultaneamente.
Visualização dos pneus em diferentes perspectivas.
Sobreposição de perfis com cores distintas.
Comparação detalhada das dimensões.
Opções de alinhamento pelo centro ou pelo solo.
Sugestões de medidas populares.
Interface responsiva e intuitiva.
🛠️ Tecnologias
HTML5
CSS3
JavaScript
Bootstrap 5
🎯 Objetivo

Facilitar a comparação de medidas de pneus, ajudando motoristas e entusiastas automotivos a entender as diferenças entre dimensões e avaliar alternativas de medidas para seus veículos.
